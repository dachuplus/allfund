## 1. 数据中心现有接口盘点（股票相关）

本项目「数据中心」页面（DataCenterPage.vue）主要归档**基金**接口（天天基金/东方财富）。
股票数据实际来自以下公开接口，已在 fetch 脚本中**实测沙箱可达**：

| 接口 | 用途 | 返回数据 |
|---|---|---|
| 东财 datacenter (`datacenter-web.eastmoney.com`) | 指数成分股 | 沪深300+中证500+中证1000 成分股代码/名称（去重后约 **1800 只 A 股**） |
| 腾讯 `qt.gtimg.cn` | 批量报价 | 最新价、涨跌幅%、换手率%、PE(TTM)、PB、总市值、流通市值 |
| 新浪 K 线 (`money.finance.sina.com.cn`) | 日线历史 | 近 3 年日线收盘价 → 区间收益 / 最大回撤 / 夏普 |
| 东财 `push2.eastmoney.com` | 行业板块成员 | 二级行业分类（best-effort，失败留空不阻塞） |

## 2. 能获取到的股票数据清单

- **基础**：代码、名称、交易所、上市日期
- **行情/估值**：最新价、日涨跌幅、换手率、PE(TTM)、PB、总市值、流通市值
- **技术/风险指标（由日线派生）**：近 1月/3月/6月/1年/3年 收益、近 1年 最大回撤、近 1年 夏普
- **分类**：二级行业（东财）
- **风控标记**：ST / *ST、退市、停牌、次新（上市 <60 天）

## 3. 股票评分方案（方法论 + 数据需求）

建议沿用基金「靠谱指数 v7」同构的 **横截面百分位 Composite** 思路，分两层：

### 第一层：因子计算（单只股票）
| 因子 | 数据源 | 状态 |
|---|---|---|
| 收益因子 `return_1y` / `return_3y` | 新浪 K线 | ✅ 已可获取 |
| 风险因子 `max_drawdown` | 新浪 K线 | ✅ 已可获取 |
| 风险调整 `sharpe` | 新浪 K线 | ✅ 已可获取 |
| 估值因子 PE / PB | 腾讯报价 | ✅ 已可获取原始值（需跨截面百分位化） |
| 质量因子 ROE / 营收增速 / 负债率 | — | ⚠️ 需补充（见 §4） |
| 动量因子 近1月/6月收益 | 新浪 K线 | ✅ 已可获取（暂未纳入） |

### 第二层：横截面百分位 + 加权合成
- 对每个因子在全市场做百分位排名（0–100）。
- `k_all = w₁·k_ret + w₂·k_drawdown + w₃·k_sharpe + …`
  （默认建议 **收益 0.5 / 回撤 0.25 / 夏普 0.25**，与基金一致；估值/质量权重后续可调）
- 风控股票（ST/退市/停牌/次新）`k_*` 置 NULL，前端按 `is_st` 等标记过滤。

**数据需求小结**：核心「技术性 + 估值 + 风险」评分，现有接口**已全覆盖**；
若要加「质量因子」（ROE、盈利增速、现金流等基本面），需补基本面数据源。

## 4. 现有接口能否满足需求？

- ✅ **满足**：价格 / 收益 / 回撤 / 夏普 / 估值(PE,PB) / 市值 / 换手 / 行业 / 风控
  —— 全部来自 腾讯 + 新浪 + 东财，沙箱实测可达，稳定性好
  （腾讯/新浪批量接口比东财 push2 更稳，已作为主源）。
- ⚠️ **缺口**：基本面质量因子（ROE、净利润增速、资产负债率、股息率等）当前接口**拿不到**，
  需额外数据源（如 东财 F10 / 财报接口、Tushare、AkShare）。
- ⚠️ **注意**：东财 push2 行业板块接口在部分网络会被限流，行业字段可能为空；
  已有降级处理（留空不影响核心评分）。
